# Starter

A small React app to build on: [Vite](https://vite.dev), [React](https://react.dev), [Tailwind CSS](https://tailwindcss.com) and [shadcn/ui](https://ui.shadcn.com).

```sh
pnpm install
pnpm dev
```

- `src/pages/` holds one file per page; `src/App.tsx` maps each to its route (`/`, `/items`, `/settings`).
- `src/components/ui/` holds the shadcn/ui components the pages use. Add more with `pnpm dlx shadcn@latest add <component>`.
- `src/data/items.ts` is sample data for the list.
